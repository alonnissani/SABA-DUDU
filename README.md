# סבא דודו — ארכיון הזיכרונות המשפחתי

אפליקציית הנצחה משפחתית פרטית: מקום אחד שבו בני המשפחה שומרים, צופים, מחפשים ומשתפים תמונות, סרטונים, הקלטות, סיפורים ומסמכים של סבא דודו.

האתר פרטי לחלוטין: אין הרשמה ציבורית, כל בן משפחה מצטרף דרך קישור הזמנה אישי, וכל קובץ מוגש רק אחרי התחברות.

## טכנולוגיה

- **Cloudflare Workers**: Worker אחד מגיש את האתר (React) ואת ה-API (`/api/*`, עם [Hono](https://hono.dev)).
- **Cloudflare D1**: בסיס הנתונים (SQLite). הסכמה ב-`migrations/`.
- **Cloudflare R2**: אחסון קובצי המקור. ה-bucket פרטי, וכל גישה עוברת דרך ה-Worker אחרי בדיקת התחברות.
- **React 19 + TypeScript + Vite**, RTL מלא, Mobile First, גופנים מקומיים (Frank Ruhl Libre, Assistant).
- **אימות**: סיסמאות מוצפנות ב-PBKDF2-SHA256 (WebCrypto), סשן בעוגיית `HttpOnly; Secure; SameSite=Lax` (במסד הנתונים נשמר רק ה-hash של הטוקן), הגנת CSRF לפי Origin, והגבלת ניסיונות התחברות.

### מבנה הפרויקט

```
worker/            ה-API: index.ts, routes/ (auth, items, uploads, files, search, admin), lib/
src/               ה-Frontend: screens/, components/, api/, styles/
shared/            טיפוסים וקבועים משותפים (קטגוריות, סוגי קבצים, מגבלות גודל)
migrations/        סכמת D1
public/            manifest, אייקונים, service worker
tests/api/         בדיקות API בתוך סביבת Workers (D1 + R2 מקומיים)
tests/e2e/         בדיקות דפדפן (Playwright): מובייל ומחשב
scripts/           ייצוא הארכיון, יצירת אייקונים
```

## הרצה מקומית

```bash
npm install
cp .dev.vars.example .dev.vars        # וערכו את SETUP_TOKEN
npm run db:migrate:local
npm run dev                           # http://localhost:5173
```

בכניסה הראשונה תופנו ל-`/setup`. מזינים את `SETUP_TOKEN` ויוצרים את חשבון המנהל הראשון.

### בדיקות

```bash
npm run typecheck      # TypeScript, בלי שגיאות
```

## פריסה ל-Cloudflare (פעם אחת)

> צריך חשבון Cloudflare. התוכנית החינמית מספיקה להתחלה. R2 חינמי עד 10GB, ואחר כך כ-0.015$ ל-GB בחודש.

1. **התחברות:**
   ```bash
   npx wrangler login
   ```
2. **יצירת בסיס הנתונים:**
   ```bash
   npx wrangler d1 create saba-dudu-db
   ```
   מעתיקים את ה-`database_id` שמתקבל לקובץ `wrangler.jsonc`, במקום `REPLACE_WITH_YOUR_D1_DATABASE_ID`.
3. **יצירת אחסון הקבצים:**
   ```bash
   npx wrangler r2 bucket create saba-dudu-media
   ```
4. **(מומלץ מאוד) bucket לגיבוי:**
   ```bash
   npx wrangler r2 bucket create saba-dudu-backup
   ```
   ומסירים את ההערה משורת `BACKUP` בקובץ `wrangler.jsonc`.
5. **קוד ההקמה (סוד, לא נשמר בקוד):**
   ```bash
   npx wrangler secret put SETUP_TOKEN
   ```
   בוחרים מחרוזת ארוכה ואקראית. היא נדרשת רק פעם אחת, ליצירת המנהל הראשון.
6. **פריסה:**
   ```bash
   npm run deploy      # build + migrations + deploy
   ```
7. נכנסים לכתובת שמתקבלת (`https://saba-dudu.<חשבון>.workers.dev`), יוצרים מנהל, מעלים את התמונה הראשית ושולחים הזמנות לבני המשפחה.

### חיבור GitHub לפריסה אוטומטית (Workers Builds)

ב-Cloudflare Dashboard ← **Workers & Pages** ← ה-Worker `saba-dudu` ← **Settings ← Builds ← Connect** ← בוחרים את המאגר `alonnissani/SABA-DUDU`:

- **Build command:** `npm run build`
- **Deploy command:** `npx wrangler d1 migrations apply DB --remote && npx wrangler deploy`

מעכשיו כל push לענף הראשי יפרוס גרסה חדשה. ב-GitHub Actions רצות בדיקות על כל push (`.github/workflows/ci.yml`).

### דומיין משלכם (לא חובה)

ב-Dashboard ← ה-Worker ← **Settings ← Domains & Routes ← Add Custom Domain**.

## אבטחה ופרטיות

- **אין הרשמה ציבורית.** הצטרפות רק עם קישור הזמנה חד-פעמי ובעל תוקף. אפשר לנעול אותו לכתובת דוא״ל מסוימת.
- **רק מנהל יכול למחוק, לשחזר, לערוך**, לנהל משתמשים ולשנות הגדרות. הבדיקה נעשית בשרת על כל בקשה, גם אם מישהו עוקף את הממשק. מכוסה בבדיקות ב-`tests/api/archive.test.ts`.
- **מחיקה רכה:** פריט שנמחק עובר לסל המחזור (״הגדרות ← ניהול תכנים״). הרשומה והקבצים נשמרים, ואפשר לשחזר בכל עת.
- **קבצים:** נבדקים סוג וגודל, ותוכן הקובץ חייב להתאים לסוג המוצהר (בדיקת חתימת בתים). כל קובץ נשמר תחת מפתח ייחודי שנוצר בשרת (`onlyIf` מונע דריסה). המקור נשמר בלי דחיסה ובלי שינוי.
- **גישה לקבצים** רק דרך `/api/files/:id`, ורק למשתמש מחובר. ה-bucket לא חשוף. התמונה הראשית ומסך הפתיחה מוצגים רק לבני משפחה מחוברים.
- האתר מסומן `noindex`, וה-Service Worker לא שומר במטמון תכנים או קריאות API.
- אין סיסמאות או מפתחות בקוד. `SETUP_TOKEN` מוגדר כסוד (`wrangler secret put`), והקובץ `.dev.vars` מוחרג מ-git.

## גיבוי ושמירת הזיכרונות

| שכבה | מצב |
|---|---|
| קובצי מקור ב-R2 (אחסון קבוע, כפול אצל Cloudflare) | ✅ פעיל מהפריסה |
| D1 Time Travel: שחזור בסיס הנתונים לכל נקודה ב-30 הימים האחרונים (7 בחינם) | ✅ מובנה ב-Cloudflare |
| גיבוי לילי (Cron, 02:00 UTC): העתקת קבצים חדשים ל-`saba-dudu-backup` + snapshot JSON של בסיס הנתונים | ✅ ממומש. **פעיל רק אחרי שלב 4 בפריסה** |
| עותק מחוץ ל-Cloudflare | ⚠️ ידני: הריצו את סקריפט הייצוא מדי כמה חודשים |

מצב הגיבויים מוצג למנהל ב״הגדרות ← מצב גיבויים״, כולל כפתור להרצת גיבוי עכשיו.

### ייצוא מלא

```bash
npm run export-archive -- --url https://YOUR-SITE --email you@example.com
```
מוריד את `manifest.json` ואת כל קובצי המקור לתיקייה `export/` לפי קטגוריות. אפשר להריץ שוב והוא ימשיך מאיפה שעצר.
גיבוי של בסיס הנתונים: `npx wrangler d1 export saba-dudu-db --remote --output backup.sql`

## הרחבות עתידיות

- **תמלול הקלטות:** ממלאים את טבלת `transcripts` (`text`, `segments_json`, `status='done'`), למשל עם Workers AI או שירות חיצוני, וקוראים ל-`reindexItem`. החיפוש יכלול את התמלול באופן אוטומטי.
- **חיפוש סמנטי:** אפשר להוסיף Cloudflare Vectorize לצד אינדקס ה-FTS הקיים (`worker/lib/search.ts`).
- **מאפיינים נוספים במסך הפתיחה:** המבנה `HeroTraits` (`shared/types.ts`) והרכיב `HeroTraitsView` מיועדים להרחבה.
- **קטגוריה חדשה:** מוסיפים ערך ל-`ITEM_KINDS` ב-`shared/constants.ts` ול-CHECK בסכמה.
